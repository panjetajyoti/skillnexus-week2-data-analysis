# SkillNexus Data Analyst Course - Week 2 Assignment

## Overview
This repository contains solutions for Week 2 assignments covering Python for Data Analysis and SQL for Data Analysis.

## Contents
1. **`python_analysis.py`**:
   - Loading CSV and inspecting schema (`info()`, `describe()`)
   - Handling duplicates and missing values via imputation
   - Aggregating revenue by category (`groupby`)
   - Multi-column sorting
   - Numerical correlation matrix computation

2. **`sql_queries.sql`**:
   - Aggregate queries finding top customers by total spend
   - Calculating Average Order Value (AOV)
   - Customer segmentation using subqueries and `CASE` statements
